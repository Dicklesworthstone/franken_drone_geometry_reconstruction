# Cross-Project Composition

The highest-value FDGR mechanisms are compounds, not isolated imports.

1. **Agent Turn Packet = one-version universe + progressive search + epistemic lattice.** One packet can summarize the entire system without mixing generations or flattening uncertainty.
2. **Question graph = scene/provenance graph + coverage + active perception + submodular selection.** The system asks which evidence changes a decision rather than collecting generic footage.
3. **Spatial MVCC = immutable geometry tiles + read/write/negative witnesses + graph conflict refinement.** Concurrent reconstruction can be safe and explainable.
4. **Branch-per-hypothesis = content-addressed history + graph branches + deterministic candidate comparison.** Competing loop closures, scales, and semantic identities remain inspectable.
5. **Incremental retraction = capsule stream + Z-set-like deltas + factor graph dependencies.** Correcting calibration or rejecting a loop closure propagates without full rebuild or hidden stale products.
6. **Proof-carrying context packs = Frankensearch retrieval + graph neighborhoods + Pack DNA + anchor continuity.** Tokens are spent on marginal decision value.
7. **Evidence-gain pilot guidance = graph algorithms + coverage/detectability + obligation verification.** Recommendations connect directly to questions and later measured results.
8. **Owned model/media workers = Asupersync regions + process sidecars + object manifests + reconciliation.** External stacks remain useful without entering the safe-Rust trust domain.
9. **Custody graph = FrankenFS publication + ATP + RaptorQ + provider-neutral object IDs.** Large evidence moves economically while roots remain stable and recoverable.
10. **Semantic absence = negative MVCC witness + authorized coverage + detectability + search completeness.** “Not found” becomes a defensible scoped claim rather than a guess.
11. **Agent accretion = episode capsules + surprise + Eidetic memory + Doodlestein qualification.** Lessons improve future operation only through evidence, replay, shadow, and rollback.
12. **Locally qualified self-description = registries + generated docs + exact source closure.** The agent knows what is truly available on this machine and profile.
13. **Multi-agent safe parallelism = region ownership + leases/fences + branch isolation + semantic reservations.** Agents cooperate without filename locks or stale publication.
14. **Cost-aware reconstruction = operation witnesses + expected-loss policy + actual/predicted episode ledgers.** Compute, storage, tokens, and operator effort become jointly optimizable.
15. **Forensic replay = immutable evidence + deterministic lab + decision/complexity certificates + span-preserving reports.** A failure can be reconstructed rather than narrated.
16. **Adaptive but non-bypassable operation = policy epochs + hard invariant ceiling + canary rollback.** Learning can improve effort allocation without weakening proof.
17. **One narrow waist = FastMCP presentation + typed semantic core + context-pack profiles.** Surface area stays small while capability remains broad.
18. **Root-last handoff = context pack + active obligations + sealed immutable object.** Agent replacement does not lose continuity or authority state.
19. **Topology-aware semantic resolution = geometry + graph cuts/connectivity + multimodal observations.** Rooms, portals, equipment, and access relations reinforce or contradict labels.
20. **Stopping as a certified decision = VOI + coverage + hard predicates + budget ledger.** The system knows when more work is waste or unsafe.
