# Agent Acceptance Scenarios

These scenarios qualify the agent operating model from the driver's seat. Schema validation alone
is insufficient.

## Scenario matrix

| ID | Scenario | Required evidence |
|---|---|---|
| A-001 | Cold campaign arrival | One briefing establishes continuity, authority, active work, top questions, and safe next step. |
| A-002 | Unchanged pulse | Byte-stable compact heartbeat; no unchanged inventory; active hazards retained. |
| A-003 | Delta after new capture | Exact basis/target continuity and semantic changes; no mixed generations. |
| A-004 | Capture-clock reset | Reset status, invalidated handles/plans, recovery action, and new epoch. |
| A-005 | Question-directed context | Pack contains sufficient diverse evidence and names omissions/Pack DNA. |
| A-006 | Model disagreement | Separate proposals, counterevidence, resolution options, no forced merge. |
| A-007 | Metric refusal | Relative geometry cannot satisfy metric objective; scale-acquisition affordance returned. |
| A-008 | Coverage-limited absence | Empty search cannot resolve physical absence without detectability/coverage proof. |
| A-009 | Candidate frontier | Same basis/policy produces deterministic nondominated alternatives and dominance reasons. |
| A-010 | Budget exhaustion | Decision-useful complete prefix, explicit omission list, sealed continuation. |
| A-011 | Active obligation handoff | Fresh agent safely resumes without transcript or hidden handle state. |
| A-012 | Indeterminate upload/device effect | Reconciliation outranks retry and effect state remains visible in every packet. |
| A-013 | Live pilot guidance | One primary instruction, fallback, safety state, expected gain, observed gain verdict. |
| A-014 | Surprise | Prediction divergence produces durable surprise and episode capsule. |
| A-015 | Policy non-bypass | Lesson/recommendation/memory cannot issue capability or weaken evidence gates. |
| A-016 | Multi-agent overlap | Lease and witness conflict both visible; deterministic rebase/branch result. |
| A-017 | No useful action | Zero-action/stop recommendation is allowed and explained. |
| A-018 | Error pedagogy | Error packet preserves valid state and names exact minimum safe recovery. |
| A-019 | Semantic zoom | Campaign summary expands to raw evidence and back without identity drift. |
| A-020 | Live/reference parity | Same semantic state yields equivalent turn packet and recommendation ordering. |
| A-021 | Decision-frame-only continuation | A fresh agent chooses the correct next protocol step from one frame and typed expansions. |
| A-022 | Attention hysteresis | Unchanged proposals do not re-interrupt; a material contradiction deterministically re-enters. |
| A-023 | Spatial refinement | An old human landmark resolves through patch split/supersession or reports exact ambiguity. |
| A-024 | Pilot refusal | `cannot_comply` retires or replans the card without representing a maneuver as executed. |
| A-025 | Safety preemption | Critical flight state displaces normal guidance and preserves the unfinished question bundle. |
| A-026 | Decision-theoretic stop | The frontier recommends doing nothing when additional evidence cannot justify its total cost. |
| A-027 | Canonical vocabulary | Schemas, CLI JSON, MCP, NDJSON, receipts, examples, and self-description emit one snake_case dialect and `fdgr.<name>/1` identities. |

## Measurement posture

Each scenario records:

- source commit and exact dependency closure;
- fixture/evidence roots and policy epoch;
- request, packet, and output digests;
- output tokens/bytes and resource use;
- deterministic replay command;
- positive and negative evidence;
- failure diagnosis and repair path.
