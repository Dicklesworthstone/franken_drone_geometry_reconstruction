# `fdgr-agent` — Agent cognitive and control kernel

**Status:** target crate contract; not yet a Cargo workspace member.

Owns Agent Turn Packets, Decision Frames, profiles, four-ledger projection, objectives/questions, context packs, attention, affordances, recommendations, handoffs, episodes, and accretion policy. It owns no external effect authority.

The first implementation must be simple and deterministic. Promotion into the workspace requires
the dependency-DAG, differential, cancellation, fault, schema, and agent-acceptance gates in the
comprehensive plan.
